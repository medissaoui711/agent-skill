# Performance Review Task — Django customer list

## Contract
Review the customer-list endpoint for correctness, reliability, and performance. It returns at most 100 customers, each with the customer's display name and the count of that customer's open orders. The ORM supports `annotate` and aggregate queries. The response shape and ordering must remain unchanged.

## Review scope
Inspect the supplied project file only. Report actionable defects with precise file and line locations. Do not assume indexes, database caching, or undocumented middleware behavior.
