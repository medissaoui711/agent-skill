# Agent Skills

A curated repository of reusable agent skills for software engineering workflows.

## Available skills

- `code-review-expert` — evidence-driven code review covering correctness, security, architecture, performance, maintainability, and tests.

## Installation

Install a skill with the Skills CLI:

```bash
npx skills add medissaoui711/agent-skill --skill code-review-expert
```

See each skill directory for its instructions and references.
